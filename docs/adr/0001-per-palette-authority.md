# 每套自定义色板使用独立权威记录

账号私人色板库允许每个账号保存最多十套自定义色板，并分别同步、编辑、删除和分享。我们决定在 `2048-game-api` 中为每套自定义色板建立独立权威记录和不可变版本历史，把当前色板选择与色板顺序保存为两个独立账号资源；不再把整个私人色板库作为一个 JSON 文档和一个共享 revision 进行权威写入。

## Considered Options

- **继续整库 JSON + 单一 revision**：实现简单，但两台设备修改不同色板也会冲突，删除标记、十套容量和单套分享资格都只能依赖整库状态。
- **在整库 JSON 内嵌每套 revision**：能表达按套版本，但仍要求并发写回同一文档，锁和迁移边界不清晰。
- **每套色板独立记录**：与稳定 palette ID、按套同步、永久删除标记和 Theme Plaza 按 ID 读取天然一致。

## Consequences

- 每套色板拥有独立 revision、内容、删除状态和版本历史。
- 服务器通过每账号唯一、可锁定的 palette-account state 行原子执行十套容量检查；所有创建、删除、顺序、选择和 Theme Plaza 保存事务都先锁账号状态，再按 palette ID、revision、operation 的固定顺序加锁。删除标记不占有效色板名额。
- 当前色板选择可指向 `follow-theme`、内置色板或自定义色板，并与正式色板顺序分别演进。
- 首页只读取当前选择及必要的一套自定义色板；完整私人色板库在设置页延迟加载。
- 旧 `/api/me/app-palettes` GET 仅作为兼容投影保留；旧整库 PUT 在切换后 fail-closed。
