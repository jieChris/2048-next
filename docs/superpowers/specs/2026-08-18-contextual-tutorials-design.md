# 上下文新手指引设计规格

## 状态

- 视觉方向：已确认，采用“首次真实控件聚焦 + 设置统一目录复看”。
- 页面范围：已确认并完成实施；首批自动指引为练习板、八方向和回放，其余五项从设置目录手动复看。
- 本文：实施完成，后续只在指引内容或页面结构变化时递增版本。

## 目标

让玩家在第一次进入一个有独特操作的页面或模式时，能在不阅读外部文档的情况下完成最小上手；熟悉后不再被自动弹窗打扰，同时始终可以从设置重新查看任何页面的指引。

## 非目标

- 不制作视频、长篇说明书或强制完成的互动任务。
- 不在教程中修改棋盘、游戏记录、排行榜、回放或随机数状态。
- 不新增服务端接口、账号字段或统计上报。
- 不把每个棋盘尺寸都拆成一条重复教程；只有操作语义确实不同才拆分指引。

## 用户体验

### 首次自动指引

页面完成初始化、目标控件已可见后，检查当前页面/模式对应的指引 ID：

1. 本地没有该指引的“已处理”标记时，显示半透明遮罩和单步聚焦卡片。
2. 每步只高亮一个真实控件，配一句短说明、进度点、“上一步”“下一步”和“跳过”。
3. 用户完成最后一步或点击“跳过”后，写入已处理标记；刷新页面不再次自动弹出。
4. 用户点击遮罩、按 `Escape` 或关闭按钮时，按“跳过”处理，避免反复打扰。
5. 教程不会自动替用户点击控件，也不会改变当前游戏状态。

首次指引只在页面稳定后启动，不覆盖游戏结束提示、登录弹窗、确认弹窗或其他更高优先级对话框。若页面正处于不可安全解释的状态，则延迟到状态稳定；若目标控件始终不存在，退化为居中的纯文字卡片并允许关闭。

### 设置中的统一目录

在完整设置页 `palette.html` 中增加“新手指引”入口。入口打开一个轻量目录（不新增独立站点），按功能列出可用指引；游戏内设置弹窗不重复提供该目录：

- 练习板：摆放与清除
- 八方向：斜向操作
- 回放：播放与拖动
- 普通游戏：基础操作
- 模式选择：规则怎么看
- 色板中心：配色与发光
- 5x5 接力：接力流程
- 记录与排行榜：本地和服务器数据的区别

每一项显示标题、简短说明和箭头；点击后：

- 当前页面：从设置目录直接打开对应指引；
- 其他页面：保留必要的模式参数，导航到目标页面，页面初始化完成后自动打开对应指引；
- 目标页面或模式不可用：显示可理解的错误提示，不改变当前游戏。

目录入口在中文和英文界面都存在，排序稳定；“已看过”不是隐藏条件，已看过的项目仍可再次打开。

## 页面范围判定

只有同时满足以下至少一项，页面才进入新手指引目录：

- 存在不看说明很难发现的操作；
- 相同按键或手势在不同上下文中的语义容易误解；
- 控件较多，播放、导入或数据流转关系不直观；
- 操作会写入服务器或不可恢复，需要在执行前说明边界。

普通导航、表单填写、显而易见的筛选器和已有清晰页内说明的功能，不再叠加首次弹窗。

### 页面覆盖总表

| 页面或场景 | 触发方式 | 是否首批实施 | 主要原因 |
| --- | --- | --- | --- |
| `Practice_board.html` 练习板 | 首次自动；设置可复看 | 是 | 摆放、`0` 循环和手势模式都较隐蔽 |
| `play.html` 八方向模式 | 首次进入八方向模式自动；设置可复看 | 是 | 斜向操作及 `Z` 键语义容易误解 |
| `replay.html` 回放 | 首次自动；设置可复看 | 是 | 播放、定位、速度和导入控件较多 |
| `modes.html` 模式选择 | 仅设置目录手动打开 | 否，第二批 | 需要解释规则差异，但不应打断选模式 |
| `palette.html` 色板中心 | 仅设置目录手动打开 | 否，第二批 | 功能多，但首次弹出会打扰普通设置 |
| `relay_5x5.html` 5x5 接力 | 仅设置目录手动打开 | 否，第二批 | 流程复杂，且部分操作会写入服务器 |
| 普通游戏页 | 仅设置目录手动打开 | 否，第二批 | 页面已有基础玩法提示，不重复自动弹出 |
| `history.html`、排行榜和用户记录页 | 页内短说明；设置目录提供数据说明 | 否，第二批 | 重点是解释本地与服务器记录边界 |
| 触屏灵敏度、账号和成就页 | 仅保留页内说明 | 否 | 现有字段和提示已经足够 |
| 管理、监测、文档、调试和预览页 | 不提供玩家新手指引 | 否 | 不属于普通玩家首次使用范围 |

## 第一优先级：首次自动提示

### 练习板（`practice-board`）

默认 3 步，内容根据当前规则集动态替换数值：

1. 高亮上方棋子选择区，说明先选择要放置的棋子。
2. 高亮棋盘格，说明点击指定位置可放置当前选中的棋子。
3. 高亮 `0` 和棋盘格，说明连续点击同一格的循环：`清除 → 不可合成砖块 → 2 → 4 → 8…`。

规则和视口差异：

- 斐波那契规则使用实际斐波那契序列，不写死幂 2 数值。
- 紧凑视口增加第 4 步：点击分数/计时区域切换到手势模式，此时滑动棋盘而不是放置棋子。
- 桌面视口不显示移动端专属步骤。
- 玩家开始移动后摆盘区会锁定；需要重新开始练习才能继续编辑。

设置目录再次查看时可以展开“高级操作”，说明练习模式选择、盘面代码、导入、撤回和重做。高级操作不塞进首次 3 步。

### 八方向（`diagonal-moves`）

只在当前模式实际允许斜向移动时注册，不在普通 `play.html` 模式中出现。首次内容包括：

1. 说明除上、下、左、右外，还支持左上、右上、左下、右下。
2. 从当前输入配置读取并展示键盘映射；当前约定为 `E` 右上、`C` 右下、`Z` 左下、`Q` 左上，小键盘 `9`、`3`、`1`、`7` 对应四个斜向。
3. 明确提示：八方向模式中的 `Z` 是左下移动，不是撤回。
4. 紧凑视口说明斜向滑动和“斜向辅助”按钮。

教程与实际输入层必须共用同一份模式配置；若两者不一致，应修复输入逻辑，不能用教程掩盖错误。当前模式是否允许撤回同样从模式配置读取，不作全局假设。3x3、4x4、4x3 和 4x2 共用一套动态教程，不按棋盘尺寸复制。

### 回放（`replay-controls`）

首次内容控制在 4 步：

1. 播放和暂停。
2. 固定速度与“按原速回放”的区别。
3. 拖动进度条定位，以及 `退 1`、`退 10`、`进 1`、`进 10` 的区别。
4. 导入回放文件或粘贴回放字符串，并说明统计信息入口。

教程必须明确：拖动、前进和倒退只改变当前查看位置，不会修改原始记录。导入说明可列出 `.txt`、`.vrs` 和 `.rpl`，但旧格式兼容细节只在实际出现兼容提示时解释，不放进首次教程。教程不自动播放长回放，也不写入新的回放动作。

## 第二优先级：只在设置目录手动查看

### 模式选择（`mode-selection`）

按机制分组说明，不为每个模式复制教程：

- 棋盘尺寸；
- 幂 2 与斐波那契规则；
- 是否允许撤回；
- 封顶模式的目标方块和结束条件；
- 八方向规则；
- 特殊出数、障碍、方向锁、连击、道具和计时等特殊规则；
- 哪些模式可载入排行榜，哪些只保留本地体验。

### 色板中心（`palette-settings`）

拆成可以独立进入的短主题：

- 计时器：母计时器与子计时器、推荐规则、保存后生效；
- 外观：主题和色板的区别；
- 方块样式：背景、文字、边框和发光；
- 边框和发光都可以选择“无”；
- 整体发光强度与单个方块发光倍率的关系；
- HEX、RGB、系统色板和预设颜色；
- 色板副本、重命名、导入和导出；
- 界面语言作用于整个网站。

### 5x5 接力（`relay-5x5`）

按实际操作顺序说明：

1. 登录要求；
2. 创建档案；
3. 读取档案；
4. 提交当前进度；
5. 申请接档；
6. 当前持有者批准；
7. 被指定用户确认接档；
8. 销档不可恢复；
9. 整档回放、分段回放和终盘快照的区别。

该教程必须标记哪些按钮会写入服务器，不能自动替用户执行创建、提交、批准、确认或销档。

### 普通游戏（`game-basics`）

仅供手动查看，内容包括：

- 相同数字合并和目标方块；
- 方向键、WASD、HJKL 和触屏滑动；
- 可撤回与不可撤回规则的区别；
- 新游戏、刷新页面和恢复当前游戏状态的区别。

刷新和恢复的文案必须通过当前实现审计后确定，不能用教程替代恢复逻辑缺陷的修复。页面已有清晰移动提示时，不再自动弹出同类内容。

### 记录与排行榜（`records-and-leaderboards`）

作为跨页面的数据说明，不逐个控件聚焦：

- 本地历史与账号服务器历史不是同一份数据；
- 上传成功、等待上传和上传失败的含义，以页面实际提供的状态为准；
- 排行榜按照当前选择的模式和指标展示；
- 筛选和排序只改变当前显示，不会删除记录；
- 导出全部与清空全部的区别，清空属于不可恢复操作；
- 用户主页中的记录筛选不会改变原始记录。

## 仅保留页内说明

- `touch_sensitivity.html`：继续使用“数值越小越灵敏、越大越不容易误触”和测试棋盘，不增加教程浮层。
- `account_settings.html`、`register.html`、`password.html`、`beta-login.html`、`beta-access.html`：使用字段说明、校验错误和流程提示。
- `account.html`、`user.html`、`medal-wall.html`：筛选器和按钮保持自解释，必要的数据边界统一放入“记录与排行榜”。
- `history.html`：保留筛选、导出和清空的短说明；不首次自动弹出。

## 明确排除

以下页面不加入面向普通玩家的新手指引：

- `admin.html`；
- `stone_2k_monitor.html`；
- `api-docs.html`；
- `ranked_seed_validator.html`；
- `cache-reset.html`；
- `ui-preview.html`、`visual-preview.html`、`favicon-preview.html` 等预览或开发页面；
- 404 页面和隐藏彩蛋页面。

这些页面继续使用各自的页内说明、权限提示或开发文档，不出现在设置中的玩家指引目录。

## 技术设计

### 指引注册表

建立一个轻量、数据驱动的注册表，不为每个页面复制一套运行器。每条记录包含：

- `id`：稳定且带版本的指引 ID，例如 `practice-board-v1`；
- `title`、`description`：中英文文案键；
- `targetPage` 和可选的模式匹配条件；
- `buildTargetUrl(context)`：生成跳转地址并保留现有模式参数；
- `steps`：目标选择器、文案键、可选的视口/模式条件和定位策略。

运行器只负责遮罩、聚焦、翻步、关闭、焦点管理和降级；页面/模式差异只放在注册表和少量上下文适配器中。

### 首次标记

使用本地存储，不上传服务器：

```text
guide_seen_v1:<guide-id> = "1"
```

标记与语言无关。用户完成、跳过、关闭都视为“已处理”，避免每次进入都打扰。以后修改教程内容时递增 ID 版本（例如 `v2`），让新版本自然重新出现，不覆盖旧数据。

### 导航参数

设置目录跨页面打开时附加一个短生命周期的 `guide` 查询参数，例如：

```text
Practice_board.html?practice_mode_key=diag_4x4_pow2_no_undo&guide=practice-board-v1
```

页面完成初始化后校验该 ID 是否属于当前上下文，打开一次并用 `history.replaceState` 清理参数，避免刷新重复触发。无效或不匹配的 ID 只忽略，不阻塞页面。

### 目标定位与降级

- 目标可见：滚动到目标并创建 spotlight，确保 tooltip 不被棋盘或弹层遮挡。
- 目标在分页/折叠中：先展开对应容器，再定位；无法展开则跳过该步。
- 目标缺失：显示不依赖 DOM 的说明卡片，并提供关闭按钮。
- 所有教程层级高于棋盘内容但低于系统级确认/登录对话框。

## 无障碍与多端

- 教程容器使用 `role="dialog"`、`aria-modal="true"` 和动态 `aria-describedby`。
- 打开时焦点进入“下一步”，`Tab` 只在教程内循环；`Escape` 关闭并记为已处理。
- 提供“跳过”文字按钮，不只依赖点击遮罩。
- 遵循 `prefers-reduced-motion`，关闭平移/缩放动画但保留高亮边界。
- 窄屏使用底部卡片，避免遮挡目标和横向溢出；桌面使用靠近目标的气泡。
- 中英文文案、按钮、`aria-label` 同步维护。

## 数据与安全边界

- 只读当前页面上下文和本地教程标记；不读取或传输账号、游戏记录、回放内容。
- 教程跳转不得调用新游戏、清理存档、上传记录或改变排行榜状态。
- 从完整设置页目录打开教程时，只启动一层教程覆盖层；游戏内设置弹窗不提供目录。

## 验收标准

1. 每个已注册页面/模式首次进入只自动出现一次；完成、跳过、关闭后刷新不再自动出现。
2. 设置目录始终可打开，已处理项目仍可复看。
3. 点击跨页面项目能保留目标模式参数，并在初始化完成后自动打开正确教程。
4. 练习板教程准确反映幂 2、斐波那契和紧凑视口的实际操作，不执行真实放置动作。
5. 八方向教程使用当前模式实际方向/按键配置，避免过时映射。
6. 回放教程不会改变播放位置或写入新回放操作。
7. 目标控件缺失、页面切换、刷新、按 `Escape` 时都能安全退出，不阻塞游戏。
8. 中文/英文、桌面/窄屏、浅色/夜间模式下，文字和聚焦层均可读且不溢出。

## 验证计划（实施阶段）

- 单元：注册表匹配、存储读写、版本键、导航参数清理、无效 ID 降级。
- 内置浏览器：首次展示/跳过/刷新、设置目录复看、跨页面跳转、不同规则集、窄屏底部卡片、中文英文和夜间模式。
- 回归：确认教程路径不触碰重开、记录上传、排行榜、回放写入和练习板实际动作。
