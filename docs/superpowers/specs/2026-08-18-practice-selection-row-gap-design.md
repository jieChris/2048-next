# 练习板选中棋子固定行距设计

## 目标

选中棋子继续保留现有 `scale(1.15)` 放大反馈，flex 行的布局间隔保持约 4px；放大后的选中项可以覆盖相邻棋子，并通过层级保证选中状态可见。

## 根因

`.selection-grid` 使用 flex 换行，基础 `gap` 是 4px。上一版用上下 `margin` 为 `transform: scale(1.15)` 的视觉扩展预留空间，改变了 flex 行高，导致未选中列出现不一致的大间距。放大本来就应当是视觉层效果，不应参与布局。

## 方案

- 保留现有 flex 换行、4px `gap`、放大效果和 `z-index: 100`。
- 给 `.selection-tile` 使用 `box-sizing: border-box`，让选中边框不改变 flex 项尺寸。
- 不添加上下 margin；复用现有 `setSelectedValue`，不新增 JavaScript 状态或布局计算。

## 验收

- 320×568 和桌面宽度下，各 flex 行的布局间距约为 4px。
- 切换第一排和第二排的选中项时，放大项可覆盖相邻棋子但始终位于其上方，横向列间距和棋子布局尺寸不被选中状态改变。
- 选中框仍位于相邻棋子之上；其他练习板放置、回放和游戏规则不变。
