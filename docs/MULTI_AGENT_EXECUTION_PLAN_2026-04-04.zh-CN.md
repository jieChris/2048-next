# Multi-Agent Execution Plan (2026-04-04)

## 1) 团队规模与角色
建议 5 个 agent 并行（A-E），足够覆盖本轮需求且沟通成本可控。

- A（主导 / 架构）：范围收敛、边界定义、方案拍板。
- B（前端实现）：练习板 UI/交互与移动端触控行为修复。
- C（核心与回放）：盘面编码解析、合法性校验、与现有棋盘模型对接。
- D（后端与平台）：55 接力模式可行性分析、服务端方案与安全模型。
- E（测试与验收）：unit/smoke/manual 验证、回归基线与发布检查。

## 2) 协作机制
- 日节奏：每日一次 10 分钟站会（昨日完成 / 今日计划 / 阻塞）。
- 任务粒度：每个任务只做一个可验证结果，禁止混改。
- 提交流程：B/C/D 各自小批次提交，A 统一审边界，E 独立验收。
- 决策机制：体验争议由 A 当天拍板，避免拉长讨论。

## 3) 本轮目标与范围
### In Scope
1. 练习板新增盘面代码输入（按钮打开输入框 + 确认）。
2. 盘面编码规则明确化并实现校验（长度映射棋盘尺寸）。
3. 练习板移除“最高分”，仅保留“分数”。
4. 移动端主题设置：打开色板后锁定页面滚动（仅面板内交互）。
5. 颜色预览移除“计时器”预览，仅保留棋盘预览。
6. 55 接力模式做可行性分析文档（不进入开发实现）。

### Out of Scope
- table 练习/测验在线化实现（仅保留为待选方向）。
- 55 接力模式代码开发。

## 4) 盘面编码规范（v1）
### 4.1 输入格式
- 仅允许字符：`0-9` 和 `A-F`（不区分大小写）。
- 编码顺序：从上到下、从左到右。
- 长度决定棋盘尺寸：
  - 16 位 -> 4x4
  - 12 位 -> 3x4
  - 9 位  -> 3x3
  - 8 位  -> 2x4

### 4.2 数值映射（v1）
- `0` 表示空格。
- `1..F` 映射为 2 的幂阶（与当前项目主逻辑保持一致）。
- v1 不允许在摆盘输入中表达 `65536`（避免与 `F` 发生二义性）。
- 默认摆盘最大值维持 `32768`。

说明：如果后续必须支持 `65536`，在 v2 设计扩展语法（例如转义前缀），不在 v1 混入。

## 5) 任务拆分（按 agent）
### A（主导）
- 审批编码规范 v1 与 UI 入口位置。
- 审批 55 接力模式分析结论与上线前置条件。

### B（前端）
- 在练习板“设置”按钮前新增“盘面输入”按钮。
- 桌面/移动端统一：点击后显示单行输入框 + “确认”按钮。
- 移除练习板“最高分”模块。
- 修复移动端色板弹层期间页面滚动穿透。
- 颜色预览区域移除计时器预览 DOM 与样式。

### C（核心）
- 新增盘面编码解析器与校验器：字符合法性、长度合法性、尺寸映射。
- 将解析结果转为当前棋盘状态并安全注入（失败时给出明确提示）。
- 增加边界防护：非法输入不得污染当前局面。

### D（平台/后端分析）
- 产出《55 接力模式可行性与安全评估》：
  - 存储位置（推荐 DB + 缓存，不走纯静态对象）
  - 锁机制（租约 lock + heartbeat + 超时释放）
  - 竞争控制（原子 compare-and-swap）
  - 审计追踪（操作日志、接力链路）
  - 安全策略（鉴权、频控、风控、反刷）
- 明确“10 分钟更新”替代方案：
  - 关键写操作实时同步
  - 列表页短轮询或 SSE 增量刷新
  - 超时自动回收编辑权

### E（测试）
- unit：编码解析、长度映射、非法输入回退。
- smoke：练习板输入盘面、移动端色板滚动锁、颜色预览变更。
- manual：iPhone Safari 基础巡检（色板、练习板、页面卡顿观察）。

## 6) 验证基线
- 必跑：`npm run test:unit`
- 必跑：练习板与主题设置相关 smoke（按现有套件）
- 必跑：`npm run verify:refactor:ci`
- 交付需附：
  - 变更文件清单
  - 测试命令与结果
  - 已知风险与后续任务

## 7) 交付物
1. 代码：练习板盘面输入 + UI 调整 + 移动端滚动修复 + 预览调整。
2. 文档：55 接力模式可行性分析（单独文档）。
3. 验证：unit/smoke/refactor gate 结果。

## 8) 批次顺序
- Batch 1（B+C+E）：练习板盘面输入 + 校验 + 最高分移除。
- Batch 2（B+E）：移动端色板滚动穿透修复 + 颜色预览移除计时器。
- Batch 3（D+A+E）：55 接力模式可行性与安全评估文档。

## 9) 完成标准（DoD）
- 练习板可通过编码稳定恢复盘面，错误输入不破局。
- 4 种长度映射全部可用，提示文案清晰。
- 练习板仅保留“分数”。
- 移动端色板打开时页面不跟随滚动。
- 颜色预览仅显示棋盘，不再显示计时器预览。
- 55 接力模式形成可执行技术方案与风险清单。
