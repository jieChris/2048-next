   - 扩展公开资料、记录和成就接口。

2. `2048-next`
   - 扩展 OpenAPI 合同并生成类型。

3. 验证
   - 运行目标单元/API测试、`git diff --check`、两仓 typecheck/build。

   - 使用内置浏览器复用一个标签检查本人、访客、标签切换、筛选和弹窗。
4. 交付
   - 复核 PRD 验收项和两个工作树 diff。
   - 进行代码审查，修复阻断项。
