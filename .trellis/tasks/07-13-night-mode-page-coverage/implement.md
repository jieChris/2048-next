# 夜间模式全页面适配

## 目标

- 夜间偏好在所有正式页面加载时生效，避免管理页和监测页停留在浅色模式。
- 清除二级页面中仍为亮白色或低对比度的面板、提示、状态标签和表单文字。
- 复用现有经典工坊夜间色板，不改变已确认的按钮结构、动画、棋盘配色和模式选择页内部设计。

## 实施

1. 用真实页面和本地 API mock 审计正式页面的夜间属性、亮色残留与文字对比度。
2. 新增共享夜间页面表面层，集中覆盖页面专属 CSS 写回的亮色。
3. 为缺少预加载器的管理页和 2K 监测页接入现有夜间偏好预加载。
4. 增加页面级 Playwright 回归，覆盖夜间属性和关键表面。
5. 逐页检查桌面、移动视口，并运行专项 Smoke、构建和预推送门禁。

## 验收

- 所有正式页面在夜间偏好开启时具有 `data-night-background="1"`。
- 用户记录、历史空状态、接力提示、危险按钮、状态标签、管理台和 2K 监测页不再出现突兀亮白表面。
- 注册、密码、用户主页和成就页的辅助文字在夜间背景下保持可读。
- 模式选择页内部样式不变。
