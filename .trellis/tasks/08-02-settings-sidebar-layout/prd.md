# 设置页侧栏布局 PRD

将“计时器”“外观与配色”从设置页顶部导航改为桌面端左侧分类栏，右侧承载当前分类内容。采用 GitHub Primer NavList 的简洁二级导航层级：导航不使用卡片容器，只保留单行分类名称；分类说明移动到右侧内容标题下。窄屏回退为双列顶部分类，保持现有 hash 切换和全部设置功能。

## 验收标准

- 桌面端左侧导航无边框、阴影或独立卡片背景。
- 当前分类仅使用青色左侧细线与浅色底色表示；非当前项不显示强调边框。
- “自定义子计时器规则”“主题、色板与棋盘预览”分别显示于其对应内容标题下。
- 小屏导航位于内容上方，两个分类均可完整点击。
- 点击“回首页”始终进入 `2048.html`，不受设置页分类切换产生的历史记录影响。
- 外观与配色页的完整工作区默认折叠；展开后才显示主题选择、色板列表、颜色编辑和棋盘预览。
