# 移动端单模式锁恢复

## 目标

- Chrome 异常退出后恢复同一标签页时，不误报同模式重复页面。
- Chrome 新标签页遇到已关闭页面留下的本地租约时，不误报重复页面。
- 即使确实打开了重复页面，冲突页退出时也不得覆盖已有棋盘存档。

## 实施顺序

1. 添加同标签页残留锁接管的单元测试。
2. 添加重复页面退出不写存档的单元测试与浏览器回归测试。
3. 在共享单模式锁和页面生命周期持久化边界做最小修复。
4. 运行目标测试、完整单元测试、关键烟雾测试与构建。

## 锁策略

- Chrome 等支持 Web Locks API 的浏览器使用浏览器进程持有的模式锁，标签页或进程退出后由浏览器自动释放。
- `localStorage` 心跳锁保留为旧浏览器回退，并继续负责存档保护。
