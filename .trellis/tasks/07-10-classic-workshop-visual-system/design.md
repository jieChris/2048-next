# “经典棋盘工坊”全站视觉系统设计

## 文档状态

- 已完成方向讨论并获得用户确认。
- 已完成真实页面预览台并获得用户确认。
- “雾青灰”视觉系统已接入正式共享样式。
- 模式选择页内部按钮与布局保持原样。

## 目标

解决“釉彩方块”按钮与现有页面配色、材质和层级不协调的问题，在保留经典 2048 气质的前提下，建立覆盖正式产品页面的统一视觉系统。

核心结果：

- 保留经典棋盘和数字方块，以冷中性雾青灰承载页面与面板；
- 将标志中的青色与金色融入交互和重要状态；
- 统一按钮、面板、表单、表格、标题和状态反馈；
- 同时整理浅色与夜间模式；
- 不改变页面业务流程和主要信息结构。

## 设计方向

名称：**经典棋盘工坊**

视觉关键词：

- 经典 2048；
- 精致桌游；
- 清爽、克制、耐看；
- 清晰的工具属性；
- 青金品牌细节。

不采用：

- 冷白科技风；
- 大面积青色或金色背景；
- 灰褐色主导的页面与面板；
- 玻璃拟态、渐变光球和装饰性发光；
- 营销式大标题和卡片堆叠；
- 普通面板的无意义悬浮动画。

## 色彩系统

### 独立棋子色板：暖釉·跃阶

- 作为独立内置棋子色板提供，不覆盖经典默认配色；
- 低阶由象牙、琥珀进入珊瑚和暖橙，`2` 与 `4` 同时拉开明度和色相；
- 中阶在砖红、金黄、焦橙之间交替，高阶转入绛红、梅紫和深酒红；
- 不采用单向橙色渐变，避免相邻等级在快速移动时混淆；
- 2048 与斐波那契复用同一套 16 级色序，并显式配置深暖黑或暖白文字；
- 相邻背景 RGB 距离不得低于 `64`，文字对比度不得低于 `4.5:1`。

### 独立棋子色板：翡翠·赭金

- 作为另一套独立内置棋子色板提供，不覆盖经典、冷青或暖釉色板；
- 以象牙、赭金和陶红建立暖色主轴，以深翡翠、酒红和梅紫承担对位与高阶结构；
- 利用同时对比增强暖感，不要求每一级都落在橙棕色相中；
- 相邻等级优先跨色相区分，同时保留清晰的明暗跃阶；
- 2048 与斐波那契复用同一套 16 级色序，并显式配置近黑或暖白文字；
- `2/4` RGB 距离不得低于 `100`，全部相邻背景距离不得低于 `64`，文字对比度不得低于 `4.5:1`。

### 浅色模式

- 页面背景：`#f3f6f5`
- 棋盘与结构色：`#b8c9c7`
- 普通面板：`#fbfdfc`
- 次级表面：`#edf3f2`
- 空棋盘格：`#dce7e5`
- 深色标题：`#3d4f52`
- 正文：`#56686a`
- 辅助文字：`#748486`
- 交互青色：`#2f86a0`
- 强调金色：`#d79b32`
- 主要操作石墨色：`#26383b`
- 危险砖红：`#a7463b`

页面和面板使用低饱和冷中性雾青灰，棋盘使用更深一档的灰青结构色；按钮保留釉面质感。分数、最佳和时间分别使用标志中的青、橙、绿作小面积强调，避免整页变成单一淡青色。

### 夜间模式

- 页面背景使用深青炭色，不使用冷蓝黑；
- 面板使用深灰绿色，与浅色雾青体系对应；
- 青色降低饱和度，避免霓虹发光感；
- 金色调整为柔和旧金色；
- 标题、正文、表格和方块保持清晰对比度；
- 只整理现有夜间模式，不新增第二套夜间主题。

## 材质与形状

- 普通面板圆角控制在 `6–8px`；
- 按钮继续使用已确认的 `7px` 圆角；
- 面板使用细灰青边框和短距离冷中性阴影；
- 可交互区域才使用青色边缘或焦点轮廓；
- 金色只作为细线、底边和小面积状态标记；
- 页面分区优先使用全宽区域、分隔线和工具栏，不把每个区域都做成浮动卡片；
- 禁止卡片嵌套卡片。

## 排版规则

- 保留项目现有 `Clear Sans`，维持经典 2048 的数字与界面识别；
- 页面主标题控制在 `30–36px`；
- 工具页和紧凑面板使用更小标题；
- 正文使用 `14–16px`；
- 表格与辅助信息使用 `13–14px`；
- 分数、计时和排名数字提高字重并保持稳定宽度；
- 标题、正文和辅助文字形成三级清晰层次；
- 不使用随视口宽度缩放的字体。

### 状态规则

- 普通按钮：暖白控件表面、深色文字、灰青边框；悬停使用青色轻染、边框和轻位移。
- 主要操作：石墨底、浅色文字；金色仅作小面积底边，不作为普通状态底色。
- 分段控件选中：石墨底、浅色文字；未选中保持中性控件表面。
- 列表或卡片选中：中性表面、青色边框或左边条，不使用整块深色填充。
- 开关开启：青色轨道与滑块位移；关闭为中性灰。浅色和夜间保持相同语义。
- 键盘焦点：统一 `2px` 青色轮廓。
- 禁用：中性降权并保留形状差异，不保留青色活动边条。
- 危险与错误：砖红；成功：绿色；两者同时使用文字、图标或结构，不只依赖颜色。
- 金色只用于最佳成绩、成就、里程碑和主要操作的小面积品牌细节。

### 页面分布

- 游戏页：棋盘是第一视觉焦点；分数、最佳、计时使用统一深色数字，颜色只作小面积角色标记。
- 模式页：保留现有布局与按钮结构，画布、面板、文字、边框、标签状态接入全站角色。
- 历史、账户、用户、接力、管理：使用统一面板、表头、行悬停、分页、危险和禁用状态。
- 色板、触屏与设置弹窗：工具表面使用统一中性色；主题与棋盘选择区复用次级表面和结构边框，彩色预览和数字块是内容，不污染外围控制层。
- 回放页：保留经典棋盘与数字块；分数、单步时间、进度、导入状态和弹窗复用全站表面、文字、边框与交互角色。
- 成就页：允许金色承担成就与里程碑叙事，普通筛选和选择状态仍遵循全站交互规则。

### 实现边界

- 复用现有 `--app-*` token 作为唯一基础来源，不新增主题框架。
- `--workshop-*`、`--enamel-button-*` 与页面私有 token 只作为兼容别名。
- 优先修改共享 token 和共享组件；仅在页面确有独特内容角色时保留页面级颜色。
- 不修改业务流程、布局、数字块颜色或后端边界。
