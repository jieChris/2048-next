# “经典棋盘工坊”全站视觉系统设计

## 文档状态

- 已完成方向讨论并获得用户确认。
- 已完成真实页面预览台并获得用户确认。
- “暖雾象牙”视觉系统已接入正式共享样式。
- 模式选择页内部按钮与布局保持原样。

## 目标

解决“釉彩方块”按钮与现有页面配色、材质和层级不协调的问题，在保留经典 2048 气质的前提下，建立覆盖正式产品页面的统一视觉系统。

核心结果：

- 保留经典暖米色、棕灰色、棋盘和数字方块；
- 将标志中的青色与金色融入交互和重要状态；
- 统一按钮、面板、表单、表格、标题和状态反馈；
- 同时整理浅色与夜间模式；
- 不改变页面业务流程和主要信息结构。

## 设计方向

名称：**经典棋盘工坊**

视觉关键词：

- 经典 2048；
- 精致桌游；
- 温暖、克制、耐看；
- 清晰的工具属性；
- 青金品牌细节。

不采用：

- 冷白科技风；
- 大面积青色或金色背景；
- 玻璃拟态、渐变光球和装饰性发光；
- 营销式大标题和卡片堆叠；
- 普通面板的无意义悬浮动画。

## 色彩系统

### 浅色模式

- 页面背景：`#f4f1ea`
- 棋盘与结构色：`#c7bdb2`
- 普通面板：`#fffcf6`
- 次级表面：`#f0ebe4`
- 空棋盘格：`#e2dbd2`
- 深色标题：`#514a44`
- 正文：`#655e57`
- 辅助文字：`#81786f`
- 交互青色：`#2f86a0`
- 强调金色：`#d79b32`
- 主要操作石墨色：`#26383b`
- 危险砖红：`#a7463b`

页面和面板使用低饱和暖白，棋盘使用灰褐结构色；按钮保持原有暖白釉面。分数、最佳和时间分别使用标志中的青、橙、绿作小面积强调。

### 夜间模式

- 页面背景使用深青炭色，不使用冷蓝黑；
- 面板使用深灰绿色，与浅色雾青体系对应；
- 青色降低饱和度，避免霓虹发光感；
- 金色调整为柔和旧金色；
- 标题、正文、表格和方块保持清晰对比度；
- 只整理现有夜间模式，不新增第二套夜间主题。

## 材质与形状

- 普通面板圆角控制在 `6–8px`；
- 按钮继续使用已确认的 `7px` 圆角；
- 面板使用细棕灰边框和短距离暖灰阴影；
- 可交互区域才使用青色边缘或焦点轮廓；
- 金色只作为细线、底边和小面积状态标记；
- 页面分区优先使用全宽区域、分隔线和工具栏，不把每个区域都做成浮动卡片；
- 禁止卡片嵌套卡片。

## 排版规则

- 保留项目现有 `Clear Sans`，维持经典 2048 的数字与界面识别；
- 页面主标题控制在 `30–36px`；
- 工具页和紧凑面板使用更小标题；
- 正文使用 `14–16px`；
- 表格与辅助信息使用 `13–14px`；
- 分数、计时和排名数字提高字重并保持稳定宽度；
- 标题、正文和辅助文字形成三级清晰层次；
- 不使用随视口宽度缩放的字体。

## 页面家族

### 游戏页面

代表页面：

- `2048.html`
- `Practice_board.html`
- `play.html`
- `undo_2048.html`
- `capped_2048.html`

原则：

- 不改变棋盘、计分和计时榜的核心位置；
- 优化顶部区域、间距、计分表面和页面背景关系；
- 移动端继续保证按钮、分数和棋盘优先出现在首屏；
- 保留顶部图标的真实 SVG 和独立动画。

### 账户与内容页面

代表页面：

- `account.html`
- `account_settings.html`
- `user.html`
- `history.html`
- `replay.html`
- `medal-wall.html`
- `palette.html`
- `register.html`
- `password.html`

原则：

- 减少卡片套卡片；
- 使用清晰的页面分区、工具栏、表格和表单层级；
- 表单控件与按钮保持高度和基线一致；
- 筛选、分页、危险和禁用状态使用统一视觉语言。

### 管理与工具页面

代表页面：

- `admin.html`
- `relay_5x5.html`
- `stone_2k_monitor.html`
- `touch_sensitivity.html`

原则：

- 保持高信息密度和工作效率；
- 不使用营销式布局和大面积装饰；
- 统一工具栏、分页、表格、状态和批量操作。

### 模式选择页

- `modes.html` 内部按钮和布局保持不变；
- 只协调页面背景、标题、外围间距和全站基础文字颜色；
- 继续作为已认可的视觉参照。

## 交互与动态

- 保留按钮色带扩展、收缩和按压反馈；
- 保留顶部图标各自的 SVG 动画；
- 普通静态面板不增加悬浮动画；
- 可点击区域最多使用轻微颜色变化和 `1px` 位移；
- 选中状态使用青色边缘与暖色表面；
- 金色动画只用于成就、最佳成绩和重要里程碑；
- 键盘焦点使用清晰的青色轮廓；
- 移动端点击区域不小于约 `44px`；
- `prefers-reduced-motion: reduce` 下关闭位移、旋转和装饰过渡；
- 不增加整页入场动画。

## 真实页面预览台

### 布局

- 顶部使用分段控件切换页面、设备视口和浅色/夜间模式；
- 下方始终左右并排：
  - 左侧为当前正式页面；
  - 右侧为“经典棋盘工坊”候选主题；
- 窄屏下两列按顺序纵向排列。

### 真实性

- 两侧加载相同的真实页面、DOM、SVG、样式和组件行为；
- 候选主题只注入右侧预览环境；
- 正式页面样式在确认前不得修改；
- 不使用简化占位按钮或重新绘制的假组件；
- 允许悬停、聚焦、展开和安全的本地切换；
- 拦截跳转、提交、删除和其他危险业务操作。

### 首批代表页面

- `2048.html`
- `Practice_board.html`
- `account.html`
- `account_settings.html`
- `medal-wall.html`
- `relay_5x5.html`

这些页面覆盖游戏、移动控制、表单、表格、筛选、危险状态和密集工具界面。其他页面在正式应用阶段复用同一视觉系统，不必全部塞入首批预览台。

### 无后端要求

- 未连接后端时仍必须能够查看主要布局和视觉状态；
- 预览环境可使用只读示例状态补足表格、用户信息、成就和工具状态；
- 示例状态只能改变展示内容，不得替换真实组件结构；
- 不得向后端提交数据。

## 正式范围

纳入：

- 游戏、练习板、账户、历史、回放、成就、色板、注册、密码、用户、管理、接力、监测和触屏设置页面；
- 浅色与夜间模式；
- 桌面与移动布局。

排除：

- `beta-login.html`
- `beta-access.html`
- API 文档；
- 缓存重置页；
- favicon、成就 Toast 等展示页；
- UI 预览页本身；
- Ranked Seed Validator 等开发验证工具。

## 验收标准

- 当前版与候选版可以在同一预览台中真实并排比较；
- 浅色和夜间模式均可切换；
- 桌面与移动视口均无横向溢出、遮挡或文字越界；
- 釉彩按钮不再像独立贴入页面的外来组件；
- 棋盘、方块和经典暖色气质仍然是页面第一视觉印象；
- 模式选择页内部设计保持不变；
- 预览阶段不修改正式页面；
- 用户明确确认预览后，才进入分批应用计划。
