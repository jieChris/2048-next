## Route Deviation

- `.trellis/scripts/get_context.py` 在当前仓库不存在，因此改为直接读取 `.trellis/spec/index.md`、`frontend-api-boundary.md` 与 `cross-repo-architecture.md`。
- 早期并排预览阶段，两个真实游戏 iframe 会触发项目原有的“同一模式只能打开一个页面”锁。采用最保守的例外：仅当 URL 明确带有 `?visual_preview=1` 时跳过该锁；普通正式页面与其他查询参数仍保持原行为。
- 本地未启动 `2048-game-api` 时，Vite 会记录 `/api/*` 代理连接失败；预览台继续使用只读 fixture，未新增前端 API 或持久化逻辑。
