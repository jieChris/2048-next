# 实施顺序

1. 为输入管理器增加不破坏既有 `move` 载荷的输入元数据旁路，覆盖标准、八方向、撤回和 capped 输入管理器。
2. 让移动节流整体携带方向与输入元数据，被覆盖的尝试不产生结果。
3. 在真实移动／撤回执行点生成有效或无效结果，补充当前局有效输入数和无效输入数。
4. 将操作反馈从 `keydown` 监听改为消费已确认结果，并实现稳定 ID 的八槽位增量渲染。
5. 按批准稿实现经典／雾青灰键帽、自绘粗箭头和退格图形、红色无效状态及上推动效。
6. 统一锁定／编辑的固定几何，移除状态相关主体内边距，验证锁定不位移和右侧锚点。
7. 在统计汇总面板增加有效输入数与无效输入数，不扩展到其他页面或服务端。
8. 先写失败测试，再逐层实现；运行定向 Vitest、TypeScript、构建、差异检查和内置浏览器视觉验证。
