# 上下文新手指引设计

完整范围沿用 `docs/superpowers/specs/2026-08-18-contextual-tutorials-design.md`。

最终实现采用一套轻量 DOM 运行器和数据注册表：页面只提供上下文，注册表提供中英文步骤和目标选择器，运行器负责遮罩、目标框、卡片定位、翻步、焦点和关闭。视觉使用 2048 的木质棋盘色与纸质规则卡语义，不复制现有设置弹窗。

- 聚焦框通过目标元素的实时边界定位，不克隆、不触发目标。
- 桌面卡片优先放在目标下方或上方；窄屏放在不遮挡目标的一侧。
- URL 中的 `guide=<guide-id>` 是显式复看入口，初始化后从地址栏移除；设置目录跨页使用同一参数。
- 首批自动入口只在练习板、实际八方向模式和回放页面启用；普通游戏及其余五项仅由设置目录打开。
- 设置目录链接与运行器根节点使用同一数据值但不同选择器范围，运行器只以 `.contextual-guide-root` 判断是否已打开。
- 教程关闭后恢复原焦点和滚动状态；所有事件监听随 DOM 移除。
