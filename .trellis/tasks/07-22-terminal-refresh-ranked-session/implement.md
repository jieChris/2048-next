# 终局刷新后的排位会话轮换

## 目标

- 游戏结束后立即刷新页面，当前记录仍可从本地待上传状态恢复并提交。
- 刷新后的棋盘必须使用新的排位会话，不得复用上一局已结束的 seed/token。
- 游戏进行中刷新仍恢复当前棋盘和 client record id。

## 实施顺序

1. 追踪终局提交、待上传持久化、排位会话清理和页面启动顺序。
2. 添加终局待上传状态存在时刷新页面的失败回归。
3. 在排位会话启动边界实施最小修复，不改变后端校验规则。
4. 运行目标单元测试、相关 Smoke 与项目检查。

## 验收标准

- 待上传终局记录与 active session 匹配时，页面启动会切换到下一排位会话。
- 待上传记录继续携带上一局 token 独立重试。
- 普通在局存档刷新不轮换会话。
