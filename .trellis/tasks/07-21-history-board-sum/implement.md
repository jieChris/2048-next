# 历史记录盘面和实施计划

1. 扩展历史记录契约与规范化测试，集中定义盘面和算法。
2. 在新局结束记录生成点写入 `board_sum`，并让本地存储规范化旧记录。
3. 扩展本地历史的关键词、排序、列表展示和中英文文案。
4. 验证旧记录补算、导出字段、新记录保存字段和页面排序。
5. 运行专项单测、Smoke、类型检查、构建与差异检查。
6. 将用户主页的组合排序拆为字段/顺序两个原生下拉框，并扩展 OpenAPI `sort_by=board_sum`。
7. 在 `2048-game-api` 用户记录路由中从 `final_board` 派生 `board_sum`，在分页前完成排序并返回该字段。
