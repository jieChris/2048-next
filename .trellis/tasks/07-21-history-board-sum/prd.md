# 历史记录盘面和

## 需求

- 终局历史记录保存盘面全部正数方块之和，字段名为 `board_sum`。
- 旧记录没有 `board_sum` 时，从 `final_board` 自动补算。
- 历史列表在“分数”右侧常驻显示“盘面和”。
- 历史排序增加“按盘面和（高到低）”。
- 导出后的每条记录包含 `board_sum`。
- 用户主页的云端历史将组合排序拆为“排序字段”和“顺序”两个下拉框；排序字段包含上传时间、分数、盘面和，顺序包含正序、倒序。
- 云端盘面和排序必须由权威 API 在分页前完成。

## 验收标准

- 新结束的游戏记录在进入本地历史存储前已经包含 `board_sum`。
- 旧记录不需要手工迁移也能正确显示、排序和导出。
- 中英文界面均有对应文案。
- 原有时间、分数排序与关键词筛选不受影响。
- 用户主页默认保持“上传时间 + 倒序”，并能正确请求 `sort_by=board_sum&order=asc|desc`。
