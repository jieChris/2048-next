# Smoke 稳定基线与部署门禁 PRD

## 目标

- 将当前 `Smoke (pages)` 的已知失败清零，不保留失败白名单。
- 用共享测试前置状态隔离新手指引等跨页面默认行为，避免无关用例被覆盖层阻塞。
- 将持久认证、IndexedDB 发件箱等测试更新到当前公开契约。
- 让生产部署只在同一提交的完整 Smoke 成功后继续。

## 范围

- Playwright 配置、Smoke 支持代码与失败用例。
- GitHub Actions Smoke／部署依赖关系。
- 对应 Trellis 测试规范。

## 非目标

- 不修改游戏、排行榜、认证或记录上传的产品逻辑。
- 不通过重试、扩大超时、删除有效断言或隐藏失败实现绿灯。
- 不触碰 `2048-ranked`、生产数据或后端迁移。

## 验收标准

- 最新基线中的 31 条失败均有明确归因并通过。
- `npm run test:smoke:pages` 全绿。
- 部署工作流在完整 Smoke 失败时不会执行构建和部署。
- 目标用例与完整分组通过，`git diff --check` 通过。
