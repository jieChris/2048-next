# 自定义子计时器

## 目标与用户价值

- 玩家可以用“一行一个完整表达式”的方式，为现有母计时器定义子计时进度。
- 子计时器反映棋盘真实组合；当棋盘直接进入更高进度时，低级规则以同一时间补记并明确标为越级覆盖。
- 所有模式复用同一套判断逻辑，不为可撤回模式的高阶生成规则增加模式分支。

## 已确认事实

- 现有前端已有动态子计时器行、展开状态、时间戳、存档恢复与滚动布局能力。
- 现有固定子规则从 `8192` 起按二分值自动生成，且只在合并事件上打时间戳，无法覆盖 `+2` 等生成事件。
- 可撤回 4x4 模式在最大方块达到 `131072` 后可能生成 `8`，达到 `262144` 后可能生成 `16/32/64`。
- 现有撤回不会回滚已经写入的计时器时间。

## 需求

- 删除现有自动生成的固定子计时器规则；配置为空时不显示子计时器。
- 母计时器数量不得固定为 `32～65536`：普通模式按棋盘容量生成，显式封顶模式按 `max_tile` 进一步截断，Fibonacci 模式映射相同数量的数列里程碑。
- Fibonacci 理论最大方块按可直接生成 `1/2` 的合成容量计算；3x3 母计时器显示到真实最大值 `4181`，4x4 母计时器显示到理论最大值的前一项 `2178309`。
- 练习板的 Fibonacci 摆盘预选块复用母计时器展示终点，覆盖 4x2、3x3、4x3、4x4，不得继续固定截在 `1597` 或让 4x4 暴露 `3524578`。
- 将原“主题色板”入口统一改名为“设置”，沿用 `palette.html` 作为分类设置页，不新增页面。
- 自定义子计时器编辑器放在设置页的“计时器”分类中，不再放入游戏设置弹窗；输入区默认收起，点击后展开。
- 编辑器移出后，游戏设置弹窗中的计时器开关必须恢复与其他开关相同的原有卡片宽度，不得保留全宽内联样式。
- 切换 2048 / Fibonacci 规则体系时，输入框中的规则示例必须同步切换为对应数值体系。
- 提供批量推荐规则生成：玩家选择起始和结束母计时器，系统为范围内每个母计时器生成常用关键节点，避免重复输入和手工推导组合。
- 2048 推荐规则选择范围最高到 5×5 理论最大值 `67108864`，不得显示更高且当前无实际用途的母计时器。
- 生成结果直接替换规则输入框，但不得自动保存；玩家仍需检查并点击“保存规则”后才对下一局生效。
- 设置页至少区分“计时器”和“外观与配色”，同类选项放在同一块，避免混排。
- 配置按数值规则体系保存：2 的幂模式共享一份，Fibonacci 模式单独一份；不按具体模式分别维护。
- 每条规则必须写完整表达式；允许空行分组和重复方块，例如 `32+2+2`。
- 支持多个母计时器分组，例如 `32`、`32+2`、`64`、`64+2`。
- 任一非法行使整份配置保存失败，并显示行号与原因；不得部分保存或静默忽略。
- 新配置从下一局或重新开始时生效，不改变当前在局规则。
- 每次成功移动并完成新方块生成后，用同一通用算法检查棋盘进度。
- 棋盘包含规则要求的全部方块时为精确命中；额外更小方块不影响精确命中。
- 更高进度可以覆盖低级规则，例如 `32+4` 覆盖 `32+2`、`32+16+4` 覆盖 `32+16+2`、`64` 覆盖所有 `32+...`。
- `32+8+8+4` 不得视为精确命中或覆盖 `32+16+2`，因为 `16` 尚未真正形成。
- 精确命中显示普通时间；越级覆盖显示 `时间 ↑`，并提供“由 X 覆盖”的可访问说明。
- 计时记录一旦写入便不可撤回。
- 存档、恢复和回放使用该局开局时的规则快照；后来修改配置只影响新游戏。

## 验收标准

- 空配置启动新局时不存在任何动态子计时器行。
- 游戏设置弹窗中不存在自定义子计时器编辑器；“设置”页可找到该入口，且初始为收起状态。
- 桌面端计时器开关卡片与背景音乐开关等同宽；移动端继续由共享响应式样式自然变为全宽。
- Fibonacci 规则页的输入示例使用 Fibonacci 数值，不显示 2048 的 `32+2` 示例。
- 选择 `32～64` 生成后应得到两个母计时器分组；`32` 分组包含 `32+2～32+16` 和 `32+16+2～32+16+8`，不得穷举重复方块等全部合法组合。
- Fibonacci 推荐规则使用 Fibonacci 子值，例如 `13+1～13+8` 和 `13+8+1～13+8+5`。
- 点击生成只替换当前输入内容，不写入本地存储；点击原有“保存规则”后才持久化。
- 2048 起止下拉框包含 `67108864`，但不包含下一档 `134217728`。
- 设置页入口、页面标题和相关返回入口使用“设置 / Settings”，页面内容按计时器、外观与配色分类。
- 3x3、标准 4x4、5x5 和封顶 64 模式的母计时器应分别结束于 `1024`、`131072`、`67108864` 和 `64`；缺少的高阶 DOM 行按需创建。
- Fibonacci 4x2、3x3、4x3 的母计时器分别结束于 `1597`、`4181`、`75025`；Fibonacci 4x4 的理论最大值为 `3524578`，母计时器按产品规则结束于前一项 `2178309`。
- 练习板切换 Fibonacci 4x2、3x3、4x3、4x4 后，摆盘预选块分别结束于 `1597`、`4181`、`75025`、`2178309`，且 4x4 不出现 `3524578`。
- 只配置 `32 / 32+2 / 32+4` 时，只生成对应两个子行。
- 棋盘出现 `32+4` 而未出现 `32+2` 时，两行记录同一时间，`32+2` 带覆盖标记且来源为 `32+4`。
- 只配置 `32+2` 时，棋盘出现 `32+4` 仍会覆盖并记录 `32+2`。
- `32+16+2+2` 精确命中 `32+16+2`；`32+16+4` 越级覆盖；`32+8+8+4` 不命中。
- 可撤回模式直接生成高阶方块后使用相同算法产生覆盖标记，不存在模式专用判断。
- 修改配置后继续当前局不改变计时行；重新开始后使用新规则。
- 恢复旧存档时规则、命中类型、覆盖来源和时间保持不变。

## 范围外

- 不修改任何模式的方块生成概率或档位规则。
- 不执行玩家脚本，不支持任意表达式语言。
- 不新增服务端配置或账户同步。
