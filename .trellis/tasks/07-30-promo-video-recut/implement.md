# 推广视频重剪执行计划

## 执行前提

- 用户复核并批准 `prd.md` 与 `design.md` 后才开始修改宣传素材或 CapCut 工程。
- 第一版素材、成片和 CapCut 草稿 `0730` 保持不变。
- 新版使用独立输出目录和 CapCut 草稿副本。
- 不修改网站正式产品逻辑；宣传专用盘面、API 数据、输入历史和转场遮罩仅用于录制与剪辑。

## 1. 建立新版工作区

1. 复制 `output/promo-2026-07-30/capture-promo.mjs` 到新的宣传素材目录。
2. 创建独立的 `raw`、`stills`、`audio`、`mattes` 和 `final` 子目录。
3. 复制 CapCut 草稿 `0730` 为新版草稿，使用清晰的新名称，不覆盖旧草稿。
4. 建立执行记录文件；若出现被迫偏离方案的极端情况，立即记录到其中的“Route Deviation”章节。

## 2. 统一录制环境

1. 固定 Chromium 视口和录屏输出为 1920×1080、60 fps。
2. 所有终章之前的页面写入“经典”主题和“跟随主题”棋盘配色。
3. 统一简体中文、虚拟用户身份、虚拟历史与排行榜数据。
4. 隐藏浏览器边框、系统通知、调试参数、异常弹窗和无关鼠标光标。
5. 固定游戏页面缩放与裁切，预留左侧字幕区和最右侧输入历史区。

## 3. 实现宣传专用输入历史覆盖层

1. 在新版录制脚本中注入独立 DOM/CSS 覆盖层，不进入网站正式代码。
2. 普通方向键约 54×54 像素，最多显示 8 项；最新输入从底部滑入，旧输入向上移动并逐级变淡。
3. 输入显示比 `game_manager.move` 提前约 1–2 帧；斜向模式使用真实 `↙` 等符号。
4. `Z` 键帽约 84×84 像素，使用墨黑底、亮色描边和毛笔字形，并采用更大的纵向推移距离。
5. 为覆盖层增加宣传录制断言：输入数量、最新符号、顺序和撤回键尺寸必须正确。
6. 不为方向输入添加逐键音效。

## 4. 重新录制棋盘素材

1. 按已验证序列依次录制标准 4×4、标准 3×3、斐波那契 3×3、八方向 3×3。
2. 标准 4×4 在 3.5 秒内完成 16 步，A1 合成 32768，定格 1 秒；同镜头触发正式“首次 32768”成就弹窗。
3. 录制可撤回 4×4 的出生 2 死亡、减速、右侧大号 `Z`、中央水墨 `Z`、撤回、出生 4 救活和 65536 连锁。
4. 录制可撤回 3×3 的出生 2 死亡、右侧大号 `Z`、撤回、出生 4 救活和 1024 连锁；不添加中央水墨字母。
5. 录制练习板 4×4 的 15 步连锁和 A1 的 131072。
6. 每段结束前断言目标数字、目标坐标、出生值、死亡状态、撤回恢复状态和输入历史顺序。

## 5. 录制功能页面

1. 模式大厅：录制分类快速切换，保留 2.8 秒可读内容。
2. 回放：录制步进、快进和连续播放，保留 2.8 秒。
3. 历史与排行榜：分别录制最具辨识度的动作，合计 3.2 秒。
4. 用户主页：使用虚拟玩家数据，保留 2.4 秒；不露出真实邮箱或敏感信息。
5. 成就墙：API fixture 只提供普通里程碑与竞速成就；隐藏筛选按钮必须不存在；突出“32768 里程碑｜已完成 1/3”，保留 3.2 秒。
6. 不录制 5×5 接力、404 页面、彩蛋或隐藏成就。

## 6. 录制主题终章素材

1. 准备固定 4×4 盘面：A4 为空，其余位置按 `design.md` 的蛇形布局放置 2 至 32768。
2. 录制经典跟随配色、暖釉·跃阶、翡翠·赭金、冷青·跃阶四个完全对齐的状态。
3. 录制雾青灰浅色与雾青灰暗黑两段完全同构画面：相同视口、盘面、滚动位置、鼠标状态和 UI 位置。
4. 为蜕皮准备从 A1 的 32768 附近沿左下至右上扩散的不规则 alpha 遮罩；边缘带少量灰白碎屑和卷边感。
5. 抽取配色与主题关键帧，确认只有预期颜色或主题发生变化，页面布局不得跳动。

## 7. 准备 Logo 素材

1. 使用现有高分辨率透明 Logo。
2. 在白底上制作 4.0 秒开场方块颗粒消散片段。
3. 复制并倒放同一合成片段，制作 54.8–56.0 秒的 Logo 汇聚。
4. 准备 `2048next.cn` 文本，汇聚完成时显示并持续到 59.0 秒。

## 8. 素材验证

1. 使用 `ffprobe` 检查所有素材的分辨率、帧率、时长和音轨。
2. 抽取每段初始、关键合成、死亡、撤回、救活和最终定格帧。
3. 对照目标清单核验：32768、1024、2584、1024、65536、1024、131072。
4. 核对输入历史方向与逐步序列完全一致；检查两段大号 `Z` 和 4×4 中央水墨 `Z`。
5. 核对成就弹窗使用正式 32768 数据，成就墙无隐藏入口和隐藏内容。
6. 核对主题终章六种状态和蜕皮上下层完全对齐。
7. 验证失败的素材不进入 CapCut 工程。

## 9. CapCut 主轨与音乐

1. 在新版草稿建立 00.0、04.0、32.6、35.4、38.2、41.4、43.8、47.0、54.8、56.0、59.0 秒标记。
2. 从 CapCut 曲库试听 145–155 BPM、无人声、电子或游戏风曲目；要求 00.0 秒有弱前奏、04.0 秒可进入主重拍、54.8 秒可干净截断。
3. 建立主拍和半拍标记，将棋盘移动、合成、死亡、撤回、救活和页面切换对齐节拍。
4. 严格按 `design.md` 时间表放置素材，不通过拉长棋盘移动填充时长。

## 10. CapCut 视觉合成

1. 添加极简字幕，统一字体、字号、位置和快速淡入；右侧有输入历史时将字幕放在左侧或棋盘下方。
2. 对原生成就弹窗的展开阶段加速，并在文字完整出现后短暂停帧；不重做假弹窗。
3. 为可撤回 4×4 添加中央毛笔 `Z`、减速和水墨颗粒消散；与素材内右侧大号 `Z` 同步。
4. 完成终章三套棋盘配色硬切。
5. 将雾青灰浅色素材放在下层、“经典主题 + 冷青·跃阶”页面放在上层，使用不规则 alpha 遮罩逐步剥离上层；不得使用整页交叉淡化。
6. 雾青灰浅色停留后，在 53.4 秒无过渡硬切同构暗黑画面。
7. 添加开场 Logo 消散和结尾倒放汇聚。

## 11. 音效与混音

1. 大数合成使用轻量低频冲击，不掩盖 BGM 主拍。
2. 死亡处短暂抽掉鼓点；撤回添加短促反向扫频；出生 4 恢复节奏。
3. 配色切换使用短促点击或轻量切换音；蜕皮使用裂纹、纸屑和空气扫频；暗黑模式硬切使用短促低频重击。
4. 54.8 秒直接截止 BGM，同帧触发“噌～”音效与 Logo 汇聚。
5. 56.0 秒后移除所有音轨内容和混响尾音，确保最后 3 秒数字静音。

## 12. 导出与终检

1. 导出 1920×1080、60 fps、sRGB 高质量母版。
2. 导出一份便于上传的普通码率版本；两份均不得改变帧数。
3. 使用 `ffprobe` 验证分辨率、帧率、编码、音轨、3540 帧和 59.000 秒时长。
4. 用音频波形确认 56.0–59.0 秒连续绝对静音。
5. 从头到尾观看一次有声版本，检查卡点、音量、转场和字幕；再静音观看一次，检查纯视觉可读性。
6. 抽取开场、七个棋盘目标、两次撤回、成就弹窗、成就墙、四套棋盘配色、雾青灰浅色、雾青灰暗黑、Logo 汇聚和最终定格关键帧。
7. 交付新版成片路径、上传版路径、CapCut 草稿名、BGM 名、音效名和实际媒体参数。

- 新版所有修改只进入独立素材目录和草稿副本，失败时可删除副本，不影响第一版。
