# 404 方块互动玩具设计

## 交互

- 使用原生 Pointer Events 统一鼠标和触屏拖动。
- 方块状态只包含 ID、数值和百分比位置；释放时用矩形重叠率判断同值合并。
- 初始棋盘生成 5 组配对数字，共 10 个方块；每组独立从 `2、4、8、16、32、64` 等概率随机选择，允许不同组抽到相同数字。
- 合并完成后先检查盘面是否仍有同值方块：已有配对时从 `2、4、8、16、32、64` 等概率随机生成一个小方块；没有配对但存在不超过 64 的方块时，从这些小方块的值中随机选择一个并生成同值伙伴；两者都不满足时随机选择一个小数字并生成一对。
- 方块总数在 10–12 个之间弹性变化。生成后超过 12 个时，优先回收 ID 最小、值大于 64、且不参与任何配对的方块；不回收本次合并结果或新生成方块。
- 初始位置和掉落位置在棋盘安全边界内使用连续随机坐标；若候选位置与已有方块相交则重抽，最多尝试 80 次。
- 初始布局因碎片化空隙无法放满 10 个方块时整盘重抽，最多 8 次；仍失败才使用打乱后的 4×4 安全网格。游戏中的掉落若没有空位，则重新排开现有方块后再生成。无需物理引擎。
- 键盘方向键以固定增量移动聚焦方块，原生按钮提供焦点与语义。

## 边界情况

- 随机函数以可选参数传入纯逻辑函数，浏览器复用仓库现有 `randomUnitFloat`，测试注入固定序列；不增加随机数依赖或持久化种子。
- 掉落值只使用 `2、4、8、16、32、64`，高位合并结果不会直接复制为掉落方块。

## 边界

- 独立 404 页面控制器，不接入主游戏状态；只复用现有认证令牌、成就服务和解锁提示运行时。
- 成就事件使用后端幂等授予语义；缺少登录令牌、请求失败或重复授予时均静默结束，不阻塞页面互动。
- 使用 CSS 动画和现有 Clear Sans 字体，不增加依赖。
