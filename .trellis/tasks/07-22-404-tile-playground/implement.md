# 404 方块互动玩具实施计划

1. 将 404 文案和互动区域改为散落方块玩具。
2. 实现拖动、边界限制、同值合并、键盘移动和重新散落。
3. 用新单测与 Smoke 替换迷宫测试。
4. 完成首版单测、目标 Smoke、生产构建和视觉核验。
5. 将掉落规则改为 64 封顶、10–12 个弹性总数，并在缺少配对时补入一对小数字。
6. 过滤与现有方块相交的落点，并为掉落上限、持续可合成和无重叠增加回归测试。
7. 将初始数字、初始位置、掉落数字和掉落位置改为随机生成；保留无重叠、64 上限、持续可合成与 12 个上限。
8. 为随机边界、注入式测试随机源和“重新散落”生成新棋盘补充回归测试。
9. 接入 `lost_page_visited` 隐藏成就事件、解锁提示与专属图标，并补充登录边界和展示测试。
