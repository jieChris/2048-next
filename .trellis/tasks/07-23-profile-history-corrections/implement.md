# 资料页历史记录纠错

## 目标

- 正确展示 API 返回的盘面和。
- 无撤回模式名称与筛选器、摘要保持一致。
- 删除态记录不请求后端禁止访问的回放，并保留恢复入口。
- 移动端记录列表使用页面滚动，不产生嵌套滚动区。

## 实施顺序

1. 用资料页 Smoke 固定无最终盘面但有 `board_sum`、删除态无回放、移动端滚动场景。
2. 在现有记录归一化和详情渲染入口做最小修复。
3. 运行目标 Smoke、JS/CSS 检查和相关项目门禁。

## 验收标准

- `board_sum` 不再被归一化默认值覆盖为 0。
- 标准 4x4 无撤回记录显示为 `4x4（不可撤回）` / `4x4 (No Undo)`。
- 删除态详情显示恢复提示和恢复按钮，且不发送 replay 请求。
- 560px 以下视口中 `.user-record-list` 不限制高度、不独立滚动。
