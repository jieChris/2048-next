# 回放可见水印元数据

## 需求

- 新开局时固定记录当前用户 ID、用户昵称和开局时间，后续改昵称不改变该局水印。
- v1 回放保留现有模式、规则、挑战、种子、计时器规则、初始盘面和操作数据，并增加用户身份水印。
- 回放页常驻显示用户昵称和北京时间开局时间；旧回放缺少字段时兼容隐藏。
- 水印只用于可见标识和溯源，不作为服务端可信身份或核心防作弊依据。

## 验收标准

- 登录用户开始的新局导出的 v1 回放中包含开局时用户 ID 与昵称。
- 回放页导入新回放后显示正确昵称和 `Asia/Shanghai` 对应的开局时间。
- 旧 v1 与旧格式回放仍可导入，不因缺少水印字段报错。
- 服务端重演所需的现有回放动作格式保持兼容。
