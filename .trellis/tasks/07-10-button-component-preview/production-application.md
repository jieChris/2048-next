# A 方案正式页面应用说明

## 最终确认

用户已确认将预览页中的 A 方案“釉彩方块”全部应用到实际页面。

这里的“全部”指预览页已经集中确认的全部按钮类别：

- 顶部图标按钮；
- 移动端提示、撤回、计时器和操作区展开/收起按钮；
- 主要、次要、导航和普通文字操作；
- 成就筛选、分页和紧凑操作；
- 危险、加载和禁用状态；
- 接力页与 2K 监测页专用按钮。

## 排除范围

- `modes.html` 的模式选择按钮保持原设计，不接入 A 方案。
- `beta-login.html` 和 `beta-access.html` 属于临时内测流程，不接入 A 方案。
- 色板页的棋盘选择、颜色维度等分段控件保持其专用控件设计。
- 计时榜滚动箭头、设置内联文字操作等不属于本次预览确认范围的专用控件保持原样。

## 实现方式

- 新增共享样式 `style/components/enamel-buttons.css`，正式页面和预览页 A 列读取同一份规则。
- `style/main.css` 在所有基础组件之后导入共享样式，使页面专用旧规则不能覆盖已确认的按钮外壳。
- 正式页面通过 `body[data-page]` 作用域接入，并显式排除模式页、内测页和预览页。
- 预览页通过 `.preview-variant--enamel` 接入同一份规则，不再维护第二份候选 CSS。
- 所有正式 HTML 的 `style/main.css` 入口更新缓存键，确保浏览器立即读取新样式。

## 保留行为

- 顶部九种图标继续使用原 SVG 和原动画。
- 悬停时左侧深青色条扩展并变淡；移出时同步收缩并恢复深色。
- 点按继续使用原生 `:active` 下沉和缩放反馈。
- 文字按钮模式、禁用状态、键盘焦点和减少动态效果偏好继续有效。
- 不增加 JavaScript 视觉逻辑，不修改业务点击行为。

## 验证范围

- 桌面游戏页顶部按钮。
- 390px 移动端默认与展开后的全部顶部按钮。
- 练习板移动端撤回按钮。
- 账户、历史、色板、成就、接力和 2K 监测页面。
- 模式选择页排除规则。
- 中英文界面、生产构建和 CSS 生产产物。
