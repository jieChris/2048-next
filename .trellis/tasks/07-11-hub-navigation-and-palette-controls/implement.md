# 用户中心导航与色板控件统一

## 目标

- 色板中心内部交互控件复用已确认的珐琅按钮配色与反馈体系。
- “触屏灵敏度”仅在窄屏触摸设备显示。
- 练习板不显示用户中心入口。
- 已登录状态下，账号设置页的账号信息与设置区块保持居中。
- 用户中心入口始终进入 `user.html`；账号设置保留为独立入口。
- `user.html` 在缺少查询参数时可根据当前登录状态加载本人资料。

## 实施顺序

1. 为导航、练习板入口、账号设置布局、色板控件和触屏入口补充失败测试。
2. 修复共享用户入口的目标解析和练习板排除规则。
3. 为账号页与账号设置页补回独立用户中心入口，并支持本人资料回退加载。
4. 统一色板中心内部控件的设计令牌与交互状态。
5. 运行目标单元测试、页面烟雾测试和完整预推送验证。

## 设计约束

- 不修改已确认的按钮结构和动画语言，只复用现有 `enamel-buttons.css` 变量与状态。
- 色块本身继续展示真实颜色，不使用统一白色表面覆盖。
- 用户中心与账号设置是两个不同目的地，不再通过用户 ID 缓存是否存在来混用入口。
