# 玩家记录来源筛选

## Goal

玩家云端历史默认只显示本站记录；切换为“第三方记录”后才显示管理员导入且带第三方平台元数据的记录。不提供具体平台筛选，不修改 `2048-ranked`。

## Acceptance Criteria

- 来源选择仅有“正式记录”和“第三方记录”，默认正式记录。
- 切换来源会回到第一页并由后端重新分页查询，不在当前页做客户端过滤。
- 第三方记录继续显示平台徽标并支持已有回放能力。
- 缺失或非法来源参数按正式记录处理；旧内测记录不因本次筛选而丢失，只有带第三方平台 ID 的记录进入第三方分类。
- 不增加平台级筛选，不改变排行榜、统计或导入语义。
